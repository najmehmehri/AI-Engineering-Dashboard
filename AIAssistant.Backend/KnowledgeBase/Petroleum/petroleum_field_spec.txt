[SECTION: WELL-14-SPECIFICATION]
میدان نفتی: آزادگان جنوبی - چاه شماره ۱۴ (South Azadegan Well-14)
کد تجهیزات سرچاهی و منیفولد: AZ-HEX-9942
سیال بهره‌برداری: نفت خام سنگین با درجه گرانروی 18.2 API و غلظت سولفید هیدروژن H2S برابر ۳.۴ درصد مولی.
فشار تست هیدرواستاتیک مجاز منیفولد سرچاهی: 485 بار (bar) منطبق بر استاندارد API Spec 6A در رده کیفی PSL-3.
گرید متریال لوله‌های مغزی درون‌چاهی (Tubing): آلیاژ 13Cr-L80 مقاوم در برابر خوردگی محیط‌های ترش (Sour Service مطابق با الزام NACE MR0175).

[SECTION: CORROSION-INSPECTION]
الزامات تزریق مواد بازدارنده خوردگی و پایش خطوط لوله:
نرخ تزریق دوز پیوسته ماده مهارکننده خوردگی (Corrosion Inhibitor) بر پایه ایمیدازولین در خط لوله جریانی منیفولد حداقل 35 ppm تعیین شده است.
بیشینه نرخ مجاز خوردگی دیواره لوله فولادی: حداکثر 0.05 میلی‌متر در سال (معادل 2 mpy).
بازرسی ضخامت‌سنجی اولتراسونیک دوره‌ای (UT) در زانوها و نقاط تلاقی جریان: هر ۶ ماه یک‌بار منطبق بر استاندارد بازرسی لوله‌کشی API 570 الزامی می‌باشد.

[SECTION: SAFETY-ESDV]
شیرهای قطع اضطراری سرچاهی (Emergency Shutdown Valves - ESDV):
زمان بسته شدن کامل شیرهای قطع جریان کلاس 1500 در شرایط افت یا افزایش ناگهانی فشار (High/Low Pilot Trip) حداکثر 4.5 ثانیه است.
نوع اکچویتور: هیدرولیکی رفت و برگشتی تحت فشار کاری 210 بار، سازگار با روغن هیدرولیک سنتزی استاندارد ISO VG 32.
حداقل فشار مجاز مخزن ذخیره هیدرولیک برای ۳ بار فرمان قطع متوالی: 175 بار.
